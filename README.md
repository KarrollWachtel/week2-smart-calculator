# Smart Calculator

An interactive, dependency-free Python calculator with:

- Basic addition, subtraction, multiplication, and division.
- A linear equation solver for equations in the form `ax + b = c`.
- A terminal graph for linear functions in the form `y = mx + b`, plotted from
  `x = -10` to `x = 10`.

Run it with:

```text
python calculator_with_search.py
```
